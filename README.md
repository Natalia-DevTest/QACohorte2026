# 🎭 QA Automation - Cypress Course

¡Bienvenido/a a mi repositorio de automatización de pruebas! Este espacio está dedicado a almacenar, organizar y documentar todos los códigos, scripts y proyectos prácticos desarrollados a lo largo del curso de **QA Automation con Cypress**.

El objetivo principal de este repositorio es consolidar mis conocimientos en la automatización de pruebas End-to-End (E2E) y mantener un registro de mi progreso técnico.

---

## 🛠️ Tecnologías y Herramientas
* **Framework de Pruebas:** [Cypress](https://www.cypress.io/)
* **Lenguaje:** JavaScript / TypeScript
* **Entorno de Ejecución:** Node.js
* **IDE recomendado:** Visual Studio Code

---

## 📂 Contenido del Repositorio
En este proyecto vas a encontrar:
* **Pruebas de UI:** Automatización de flujos interactivos (clicks, formularios, navegación).
* **Locators & Selectors:** Buenas prácticas para identificar elementos en el DOM.
* **Assertions:** Validaciones clave para asegurar el comportamiento esperado de la app.
* **Custom Commands:** Creación de comandos personalizados para optimizar el código.
* **Page Object Model (POM):** Implementación de patrones de diseño para mantener un código limpio y escalable (si aplica).
